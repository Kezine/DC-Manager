Niveau 1 — les domaines (.tab.tab-domain)

Cinq domaines libellés remplacent les onze onglets en icône seule : libellés > icônes, l'icône seule n'est plus le régime normal (elle ne revient que sous ~1000 px, le libellé restant en title + aria-label). Un domaine ne navigue pas vers lui-même : le cliquer active sa première vue visible. 🚨 Jamais de .tab-count sur un domaine — un badge n'appartient qu'à une entrée terminale.

Niveau 2 — la barre de vues (.views-bar)

Pattern unique de sous-navigation : elle remplace à la fois l'ancien groupe déroulant « Paramètres » et les liens d'en-tête de toutes les autres sous-vues. Pastilles .view-tab, séparateur interne .view-sep, badge de comptage .tab-count (autorisé ici : une vue est terminale). Masquée quand le domaine n'a qu'une vue.

Fil d'Ariane d'en-tête de vue (.view-crumb) — remplace le bouton « ← retour »

Tiroir responsive (.nav-drawer)

Sous 760 px, les deux barres cèdent au burger et à ce tiroir : un accordéon par domaine, contenant toutes ses vues — sous-vues comprises, ce que l'ancien menu aplati omettait. En-tête = pastille utilisateur + nom + état de sauvegarde ; pied = annuler / rétablir / réglages. Cibles ≥ 44 px. 🚨 Aucun badge sur un en-tête d'accordéon ni sur le burger.
